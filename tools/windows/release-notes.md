## 下载 Windows 电脑版

1. 点下面「Assets」里的 **`YuYin-Windows-x64.zip`** 下载。
2. 右键 → **全部解压缩**（不要在压缩包里直接双击）。
3. 打开解压出来的 `YuYin` 文件夹，双击 **`YuYin.exe`**。

第一次打开如果出现「Windows 已保护你的电脑」，点 **更多信息 → 仍要运行**。
这是因为游戏没有购买数字签名证书，不是病毒。

**操作**：方向键 / 鼠标移动，Z / 回车对话，X / Esc 菜单，**数字键 1～8 弹琴**，F4 全屏。
存档在 `YuYin\www\save` 文件夹里。

不想下载？直接在浏览器里玩：<https://wxrkz123.github.io/game/>

> 这个安装包由 GitHub Actions 自动打包。发布前，它已经在 Windows 上把两条剧情分支都自动从头玩到结局，并测试过存档和读档。
