余音 —— 一生所爱（Windows 电脑版）

一个女孩用一辈子，写完一首歌。约 30～40 分钟，无战斗。


【怎么开始】

  1. 先把下载的压缩包解压：右键 → “全部解压缩”。
     不要在压缩包里面直接双击，那样游戏打不开，也存不了档。
  2. 打开解压出来的 YuYin 文件夹，双击 YuYin.exe。
  3. 如果弹出“Windows 已保护你的电脑”：点“更多信息” → “仍要运行”。
     这是因为游戏没有购买数字签名证书，不是病毒。


【操作】

  方向键 / 鼠标点击 ……… 移动
  Z / 回车 / 空格 ……… 确定、对话
  X / Esc ……………… 打开菜单、取消
  数字键 1～8 ………… 弹琴（也可以用方向键选择、或者用鼠标点）
  F4 ……………………… 全屏 / 窗口
  F3 ……………………… 画面拉伸


【存档】

  存档在 YuYin\www\save 文件夹里。换电脑时，把这个文件夹复制过去就能接着玩。
  请把游戏放在桌面、D 盘等普通文件夹里。
  不要放进 C:\Program Files 这类需要管理员权限的文件夹，否则可能存不了档。


【系统要求】

  Windows 7 及以上的 64 位系统。
