# 零基础新手教程：用 RPG Maker MV 打开、试玩、修改《余音》

> 这份教程假设你**什么都不会**。按顺序做，每一步都能看到效果。
> 文中的菜单名以 RPG Maker MV 简体中文版为准，括号里附上英文版的叫法，方便对照。

---

## 第 0 步：准备

1. **RPG Maker MV**：在 Steam 上购买并安装（建议更新到 1.6.x 版本，Steam 会自动更新）。
   语言可以在 Steam 库里右键 → 属性 → 语言 选“简体中文”。
2. **下载这个项目**：在 GitHub 页面点绿色的 **Code → Download ZIP**，解压到一个**路径里没有特殊符号**的文件夹，比如 `D:\games\yuyin\`。
   解压后你会看到：
   ```
   YuYin\          ← 游戏本体（RPG Maker MV 项目）
   docs\           ← 策划案、剧本、这份教程
   tools\          ← 生成素材用的程序（新手可以忽略）
   ```

---

## 第 1 步：打开项目

1. 启动 RPG Maker MV。
2. 菜单 **文件 → 打开项目**（File → Open Project）。
3. 找到 `YuYin` 文件夹，选中里面的 **`Game.rpgproject`**，打开。

打开后，左下角是**地图列表**（00 开场、01 琴房、02 清水村……），中间是地图，左上是**图块面板**。

> 如果提示“项目版本比编辑器新”，请先在 Steam 里把 RPG Maker MV 更新到最新版。

---

## 第 2 步：试玩！

- 菜单 **游戏 → 测试游戏**（Game → Playtest），或按 **Ctrl + R**。
- 操作方式：

| 按键 | 作用 |
| --- | --- |
| 方向键 / 鼠标点击地面 | 走路 |
| Z、空格、回车 / 鼠标点击人物 | 对话、调查、确定 |
| X、Esc / 鼠标右键 | 取消、打开菜单 |
| 按住 Shift | 跑步 |
| **数字键 1～8** | 旋律小游戏里弹琴（也可以 ←→ 选择再按确定，或用鼠标点琴键） |
| F9（试玩时） | 调试菜单，可以直接开关“开关”、改“变量”——用来跳章节测试 |

> 💡 **跳到某一章测试**：试玩中按 F9，把开关 1（序章）关掉、开关 5（第四章）打开……不过直接跳章可能缺少前面的道具，正式检查时还是从头玩一遍最稳。

---

## 第 3 步：认识编辑器的三个“模式”

工具栏上有三个重要按钮（菜单 **模式**）：

| 模式 | 快捷键 | 用来做什么 |
| --- | --- | --- |
| 地图（Map） | F5 | 用图块“画”地图 |
| 事件（Event） | F6 | 放人物、写对话、做剧情 |
| 区域（Region） | F7 | 进阶用法，本项目没用到 |

另外两个最常用的窗口：
- **数据库**（Database，F9）：角色名字、物品、系统设置……
- **插件管理器**（Plugin Manager，F10）：管理插件，本项目只有一个 `LifeSong`。

---

## 第 4 步：第一次修改——改一句台词

我们来改爷爷说的第一句话。

1. 左下角地图列表里，点 **02 清水村**。
2. 按 **F6** 切到事件模式，地图上会出现很多小方块——每个方块就是一个“事件”。
3. 在老槐树左下方找到爷爷，**双击**他，打开“事件编辑器”。
4. 你会看到上面有 **1、2、3、4** 好几个**事件页**（后面解释）。点 **1**。
5. 右边的“执行内容”里，找到这一行：
   ```
   ◆文本：无, 窗口, 下
   ：　　：【爷爷】哟，小音醒啦？
   ```
6. **双击**这一行，把文字改成 `【爷爷】哟，小音，睡醒啦？`，点 **确定**。
7. 点事件编辑器的 **确定**，然后 **Ctrl + S** 保存，**Ctrl + R** 试玩，走到爷爷面前看看！

### 关于【名字】
本项目的插件会把对话第一行开头的 `【名字】` 变成对话框上方的**名字框**。
- 想让主角说话就写 `【\N[1]】……`，`\N[1]` 会自动变成主角的名字。
- 不写【】就是没有名字的旁白。

### 常用的文字代码
| 写法 | 效果 |
| --- | --- |
| `\N[1]` | 主角名字 |
| `\C[6]……\C[0]` | 中间的字变成金色（`\C[0]` 变回白色） |
| `\I[1]` | 显示 1 号图标（口琴） |
| `\V[3]` | 显示 3 号变量的数字 |
| `\.`　`\|` | 停顿 0.25 秒 / 1 秒 |

---

## 第 5 步：改主角的名字

1. **F9** 打开数据库 → **角色**（Actors）→ 选 **林音**。
2. 把“名字”改成你喜欢的名字，确定、保存。
3. 因为台词里用的是 `\N[1]`，**整个游戏里的名字都会一起变**。

## 第 6 步：看懂“事件页”和“开关”——剧情是怎么推进的

同一个爷爷，在不同时候要说不同的话。RPG Maker 用 **事件页 + 开关** 来做到这件事：

- **开关**（Switch）就像一盏灯，只有“开/关”两种状态。本项目用开关记录剧情进度，比如：
  - 开关 2「第一章」：现在是不是第一章
  - 开关 11「一:开始找声音」：爷爷有没有让你去找声音
- **事件页**左上角有“**出现条件**”，可以勾选“开关”。
- RPG Maker 的规则：**从最后一页往前找，第一个满足条件的页面就是当前生效的页面。**

所以爷爷的 4 个页面是：

| 页面 | 出现条件 | 爷爷在做什么 |
| --- | --- | --- |
| 1 | 第一章 | 第一次见面，让你去找声音（最后打开开关 11） |
| 2 | 第一章 + 开始找声音 | “慢慢找，不着急” |
| 3 | 第一章 + 声音找齐 | 教你吹口琴 |
| 4 | 第一章 + 学会口琴 | 回家喝绿豆汤 |

在“执行内容”里，用 **◆开关的操作**（Control Switches）把开关打开，下次就会换到下一页——剧情就这样一步一步往前走。

> 全部开关、变量的意思，见 `docs/策划案.md` 第 9 节。

## 第 7 步：自己加一个会说话的人

我们在清水村加一位钓鱼的老奶奶。

1. 打开 **02 清水村**，**F6** 事件模式。
2. 在河边一块空草地上**双击**，打开新事件。
3. 名字写“钓鱼的奶奶”。
4. 双击左边的“**图像**”方框，选 `$Granny_Li`（李奶奶的图），确定。
5. “**出现条件**”勾选 **开关**，选 `0002 第一章`（只在第一章出现）。
6. “执行内容”里双击空行 `◆`，在第 1 页点 **显示文字**（Show Text），输入：
   ```
   【钓鱼的奶奶】小姑娘，你听——
   鱼咬钩的时候，浮漂会“咚”地响一声。
   ```
7. 确定 → 确定 → 保存 → 试玩！

## 第 8 步：用“旋律小游戏”写你自己的曲子

小游戏是用 **插件指令**（事件指令第 3 页 → Plugin Command）做的。复制下面任意一行就能用：

```
LifeSong Echo Harm 1,3,5,8 11 跟着吹一遍
LifeSong Feel Harm 5,3,2,1 11 用心去“听”
LifeSong Free Pno 8 20 弹你心里的声音
LifeSong Play Gtr 3:1.5,5:0.5,6,5 24
LifeSong Chapter 第六章 新的夏天 九岁·夏
```

| 写法 | 意思 |
| --- | --- |
| `Echo` | 先示范，玩家跟着弹 |
| `Feel` | 示范几乎没有声音，只能看琴键 |
| `Free` | 自由演奏（`8` = 最多 8 个音，`20` = 把弹的旋律存进 20 号变量） |
| `Play` | 直接播放一段旋律（冒号后面是拍子） |
| `Chapter` | 显示章节标题卡 |
| `Harm / Gtr / Pno / Box / Rec` | 口琴 / 吉他 / 钢琴 / 八音盒 / 竖笛（也可以直接写中文） |
| `1～7, 8` | 简谱 do re mi fa sol la si，8 是高音 do |
| `11` | 把“弹错了几次”存进 11 号变量（可以用“条件分歧”判断夸不夸玩家） |

## 第 9 步：画地图

1. 按 **F5** 进入地图模式。
2. 左上的图块面板有 **A、B、C、D** 几个标签：
   - **A**：地面（草地、土路、河水、木地板、墙壁），会自动拼接边缘。
   - **B / C / D**：树、房子、家具、路灯……
3. 选中图块，在地图上**点击或拖动**来画。在图块面板里**拖动框选**，可以一次选中一整栋房子。
4. 右键地图 = 吸管（取样）。工具栏还有铅笔、矩形、椭圆、填充、阴影笔。

> 房子的“门”那一格是可以走上去的；要让门能进屋，需要在门上放一个事件，用 **◆场所移动**（Transfer Player），触发条件选“**玩家接触**”。可以照着地图上已有的门事件改。

### 想用 RPG Maker 自带的素材？
本项目的图都是原创像素画。如果你想用软件自带的素材（RTP）：
1. 用 RPG Maker MV **新建一个空项目**（文件 → 新建项目）。
2. 打开它的文件夹，把需要的图片（`img\characters`、`img\tilesets`……）和声音（`audio\...`）**复制**到 `YuYin` 对应的文件夹里。
3. 回到《余音》，在数据库的“图块”里新建图块组，或者在事件里直接选用新角色图。

---

## 第 10 步：换音乐和音效

- 事件指令 **◆播放 BGM**（Play BGM）、**◆播放 SE**（Play SE）可以选择 `audio` 文件夹里的声音。
- 自己的音乐要准备 **`.ogg`** 和 **`.m4a`** 两种格式（同名），放进 `YuYin\audio\bgm\`（背景音乐）或 `se\`（音效）。
- 免费转换工具：Audacity（导出 OGG）、或任何支持 m4a 的转换器。

---

## 第 11 步：发布给朋友玩

1. 菜单 **文件 → 部署**（File → Deployment）。
2. 选择平台：**Windows / macOS / Web 浏览器** 等。
3. ⚠️ **不要勾选“排除未使用的文件”**（Exclude unused files）！
   小游戏用到的乐器声音（如 `YY_Harm_1`）是插件指令里调用的，编辑器“看不见”，勾了会被误删。
4. 选 Web 浏览器版，可以把输出的文件夹上传到 itch.io 等网站，朋友在网页里就能玩。

> 不装 RPG Maker 也能在电脑上试玩：安装 Python 后，在项目文件夹里运行
> `python -m http.server --directory YuYin 8080`，再用浏览器打开 `http://localhost:8080`。

## 常见问题

**Q：中文显示成方块 / 字很模糊？**
A：游戏使用 `YuYin\fonts\FusionPixel12.woff2` 像素字体。请确认 `fonts` 文件夹完整。想换字号，在插件管理器里改 `LifeSong` 的 `Font Size`（建议 12 的倍数，如 24、36）。

**Q：试玩时报错 “Failed to load: img/... ”？**
A：说明某张图片或某个声音文件找不到了，检查文件名是否改过、是否被删除。

**Q：我改坏了，怎么恢复？**
A：重新下载 ZIP，或者用 Git 恢复（`git checkout -- YuYin/data`）。建议**每改一大步就复制备份一次** `YuYin` 文件夹。

**Q：`tools` 文件夹里的程序是做什么的？**
A：那是用来“生成”本游戏美术、音乐和地图数据的 Python 程序（给想深入研究的人看）。
⚠️ **在 RPG Maker 里改过游戏后，不要再运行 `tools/build/build_data.py`**，它会用程序里的版本覆盖你的修改。
